# Infinite Mosaic Gallery

基于 **Rust + GPUI Kit** 的原生沉浸式本地图片墙。以深黑画布、直角几何磁贴和自由平移缩放为核心。

> 项目正在按阶段实现；详见 [功能路线图](docs/ROADMAP.md) 和 [设计规范](docs/DESIGN.md)。

## 技术

- Rust 2021
- [GPUI Kit](https://github.com/longbridge/gpui-kit) 0.9
- GPUI 原生异步文件夹选择器
- 自研确定性 Mosaic 几何布局和可见区域裁剪

## 快速开始

```bash
cargo run --release
# 也支持在启动时提供文件夹路径
cargo run --release -- /path/to/photos
```

需要 Rust stable、对应系统 GPUI Kit 构建依赖和图形环境。首次运行可点击「打开文件夹」浏览本地图片。

## 交互

- 鼠标左键拖动画布；滚轮以指针为锚点缩放
- 点击磁贴从原位置展开图片查看层，Esc 反向收回；←/→ 切换图片
- 「刷新」与切换递归扫描保留镜头与所选文件（仍可能因新增文件影响其他磁贴的索引布局）
- `+` / `-` 缩放、`0` 重置视角
- 进入文件夹后后台枚举图片，当前版本默认只读取当前文件夹，支持递归选项

## 缩略图与缓存

- 视口附近的图片由后台任务按需生成 768px PNG 缩略图，保留透明通道并读取 EXIF 方向；不会修改原图。
- 缓存默认位于系统缓存目录的 `InfiniteMosaicGallery/previews-v1/`，每新增一批缩略图按 512 MiB 近似预算淘汰最旧文件。
- GPUI 采用限制条目数的解码缓存，缩略图只读生成文件；聚焦时才读取原图。
- 暂不支持在设置中调整缓存额度，完整大图库压力测试尚未完成。

## 已知边界

当前版本已经实现按视口生成缩略图、磁盘缓存、有界 GPU 图片缓存，以及聚焦时同一几何块内的弹簧让位。新增了由原始磁贴矩形出发的**连续查看层变形动画**，关闭时反向收回，但它仍是独立绘制的图片层，并非 GPUI 对同一原生图片元素的跨容器迁移；完整的视觉与高 DPI 验收还需真机进行。尚未实现自动文件变更监听及发布级性能验收。不要把 MVP 当作已通过大型图库的生产版本。

项目借鉴 [Peach Video Wall](https://github.com/peach-mitao/peach) 和 [Folia PosterWall](https://github.com/chthollyphile/folia-major) 的视觉语言，但几何模板和实现为本项目原创，没有直接复制 AGPL 代码。
