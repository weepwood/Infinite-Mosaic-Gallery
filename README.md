# Infinite Mosaic Gallery

基于 **Rust + GPUI Kit** 的原生沉浸式本地图片墙。以深黑画布、直角几何磁贴和自由平移缩放为核心。

> 项目正在按阶段实现；详见 [功能路线图](docs/ROADMAP.md) 和 [设计规范](docs/DESIGN.md)。

## 技术

- Rust 2021
- [GPUI Kit](https://github.com/longbridge/gpui-kit) 0.9
- GPUI 原生异步文件夹选择器
- 自研确定性 Mosaic 几何布局和可见区域裁剪

## 快速开始

```bash
cargo run --release
# 也支持在启动时提供文件夹路径
cargo run --release -- /path/to/photos
```

需要 Rust stable、对应系统 GPUI Kit 构建依赖和图形环境。首次运行可点击「打开文件夹」浏览本地图片。

## 交互

- 鼠标左键拖动画布；滚轮以指针为锚点缩放
- 点击磁贴从原位置展开图片查看层，Esc 反向收回；←/→ 切换图片
- 「刷新」与切换递归扫描保留镜头和所选文件；现在使用持久槽位索引，新增或删除文件不会使其他图片整体换位。
- `+` / `-` 缩放、`0` 重置视角
- 进入文件夹后后台枚举图片，默认只读取当前文件夹，可选择递归扫描
- **自动同步：开 / 关**：使用操作系统文件事件监控所选目录，文件增删、重命名、图片修改后合并事件并在后台重新扫描。手动刷新始终保留

## 缩略图与缓存

- 视口附近的图片由后台任务按需生成 768px PNG 缩略图，保留透明通道并读取 EXIF 方向；不会修改原图。
- 缓存默认位于系统缓存目录的 `InfiniteMosaicGallery/previews-v1/`，每新增一批缩略图按 512 MiB 近似预算淘汰最旧文件。
- GPUI 采用限制条目数的解码缓存，缩略图只读生成文件；聚焦时才读取原图。
- **持久化磁贴位置**：打开某个文件夹后，把每张照片的相对路径映射到固定空间槽位。删除照片后槽位保留；同路径文件重新出现时回到原位；新增文件只追加新槽位。索引文件只存储在系统应用数据目录的 `InfiniteMosaicGallery/slots-v1/`，不写入照片目录。
- 文件夹重扫时，未修改图片依据文件大小与修改时间标识复用缩略图和有界 GPU 缓存。源目录只读；索引写入采用原子替换。
- 若索引损坏或不可写，图库显示错误并保留旧内容，**不会自动覆盖损坏文件**。
- 暂不支持在设置中调整缓存额度，完整大图库压力测试尚未完成。

## 已知边界

当前版本已经实现按视口生成缩略图、磁盘缓存、有界 GPU 图片缓存、跨重启稳定的图片位置以及聚焦时同一几何块内的弹簧让位。新增了由原始磁贴矩形出发的**连续查看层变形动画**，关闭时反向收回，但它仍是独立绘制的图片层，并非 GPUI 对同一原生图片元素的跨容器迁移；完整的视觉与高 DPI 验收还需真机进行。已实现文件变更监听触发的**去抖全量重扫**，尚未实现严格增量扫描、索引槽位压缩和发布级性能验收。不要把 MVP 当作已通过大型图库的生产版本。

项目借鉴 [Peach Video Wall](https://github.com/peach-mitao/peach) 和 [Folia PosterWall](https://github.com/chthollyphile/folia-major) 的视觉语言，但几何模板和实现为本项目原创，没有直接复制 AGPL 代码。
