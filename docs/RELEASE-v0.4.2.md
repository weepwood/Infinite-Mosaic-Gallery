# Infinite Mosaic Gallery v0.4.2 — Windows 画布黑屏修复

## 问题

Windows v0.4.1 实机截图显示，扫描成功并生成 5/5 张缩略图，但画布没有任何图片；显示图片数量的底部状态栏反而紧贴在顶部工具栏下方。

## 修复

- 删除画布外层独立的 `image_cache(...)` 包装元素。该包装不是 Flex 子项的画布本体，造成 `flex_1` 无法取得预期高度，视口黑屏。
- 使用 `surface.image_cache(self.images.clone())` 直接给既有 `flex_1` 画布绑定有界缩略图缓存，不改变页面布局尺寸。
- 聚焦图层同样移除独立缓存包装层，改为直接在固定定位的聚焦面板上调用 `.image_cache(self.focus_images.clone())`，避免聚焦层发生类似的尺寸丢失。
- 添加含 5 张图片的首屏可见性纯几何测试，并提供 Windows GUI 手工验收用例。

## Windows 图形验收

1. 启动程序，选择至少 5 张 JPEG/PNG/WebP 的文件夹。
2. 主窗口应显示顶部工具栏、**中间铺满磁贴的可拖动画布**及**固定在窗口底部的状态栏**。
3. 图片应显示而不是整个画面纯黑；缩略图生成期间允许存在加载占位。
4. 关闭/开启标题、执行滚轮缩放、平移、点击任意磁贴展开及 Esc 收回，检查没有出现空白或坐标错位。
5. 试验空图库、切换文件夹、调整窗口大小、最大化/还原，确保布局不再收缩。

## 发布边界

这次补丁解决一个具有强烈证据支持的布局缺陷。自动化 CI 的 Cargo 编译与单元测试不包含真实 Windows GPU 截图对比，因此**图形修复仍需下载此版本并在 Windows 桌面验证**。

原有 v0.4.1 文件同步、持久布局与缓存稳定性修复均保留。便携包尚未进行数字签名和 Windows 安装器打包。
