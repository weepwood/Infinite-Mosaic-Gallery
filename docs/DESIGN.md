# Infinite Mosaic Gallery · 界面规范

## 设计语言

- **Infinite Canvas Mosaic UI**：自由探索的空间画布；有限本地照片，不重复制造“无限内容”。
- **Editorial Geometry**：12×8 格几何模板，12 张照片一组；相邻块左右／上下镜像保持韵律。
- **Cinematic Dark**：`#070707` 背景、`#f7f4ee` 主文字、`#aaa7a2` 次文字、`#151419` 占位底色。
- **Raw Rectangles**：所有图片磁贴直角，约 6 个世界坐标像素的间距，不使用瀑布流和厚重卡片边框。
- **Content First**：图片 `cover` 填充磁贴，大图 `contain` 完整展示；下方渐变遮罩兼容长文件名。
- **Minimal Chrome**：顶部原生 Kit 控件负责文件夹与视图切换，底部只显示真实状态及快捷键。

## 几何系统

- Grid pitch: 98 world px
- Gap: 6 world px
- Block: 12 × 8 单位
- Block columns: 3
- Tiles per block: 12
- Scale: 0.25–2.8，初始 0.84
- Culling padding: 每边 320 screen px

世界坐标、视口坐标严格分离。图片位置由文件在稳定排序列表中的索引决定；未来如需增量刷新保持位置，必须引入持久图片 ID + 空槽填充，不能在更新时随意重排。

## 交互契约

| 输入 | 行为 |
| --- | --- |
| 画布拖动 | 左键按住，位移超过 6px 才判定拖动；抑制拖动后的点击 |
| 滚轮 | 以鼠标所在点为锚点缩放 |
| Shift + 滚轮 | 横向平移 |
| 单击磁贴 | 聚焦该图片、弱化周围图片，完整查看 |
| Esc | 退出图片聚焦 |
| ←/→ | 聚焦时切换上一张/下一张，非聚焦时平移 |
| + / - | 以画布中心缩放 |
| 0 | 重置镜头 |

## 后续高级动效契约

原创的 6×6 焦点区域及邻居让位已经实现，位置与尺寸使用 GPUI Base Spring 过渡。查看层的几何从当前照片磁贴所在的屏幕坐标出发，平滑变为居中的大图区域；当关闭时保持最后一张图片的绘制直至退出动画结束。此实现属于独立图片层的**连续几何变形**，不应误称为底层 GPU 纹理共享或跨容器共享元素。触控双指手势与全面视觉回归依然**尚未完成**，动画由稳定目标和原生 GPUI Spring 驱动，不应创建无限制的帧循环。

## 无障碍与稳定性

- 工具按钮必须有可见名称，不依赖纯图标语义。
- 本地路径可能很长；文件错误应当保留用户再次打开的入口。
- 图片内容不可被文件名视为可信可执行数据。
- 图片扫描不在 UI 线程，后台结果应检验请求序号，不得覆盖更新文件夹。
- 对于大图库，绝不能为所有图片同时创建 GPUI 图片元素。
