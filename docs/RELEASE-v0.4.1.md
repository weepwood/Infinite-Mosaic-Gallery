# Infinite Mosaic Gallery v0.4.1

**发布类型：稳定性修复 / 首个正式 GitHub Release（原生桌面程序）**

本版基于 v0.4.0 持久磁贴槽位功能，重点修复长时间运行与图库批量更新下的稳定性。

## 本版修复

- **限制并发目录扫描**：初始扫描运行时，文件监控产生的多次刷新请求合并成一次后续扫描，避免大量后台扫描同时读取同一图库。
- **减少无关文件引发的刷新**：新增、删除普通非图片文件不会触发整库扫描；文件夹结构及图片变化仍然触发。
- **缩略图可靠性**：发布 PNG 缓存前显式刷新写入缓冲，并再次检查原图大小与修改时间，避免生成中修改的图片被写进错误版本的缓存键。
- **验证增强**：增加后台扫描队列合并、目录切换、文件事件过滤的 Rust 单元测试。

## 已有主要功能

Rust + GPUI Kit 原生桌面图片墙；原创 12×8 几何磁贴与 6px 间距；无限画布式平移缩放；图片原位放大动画；异步扫描/缓存/可视区域裁剪；本地目录自动同步；跨启动保存空间槽位，删除照片不挤压其余磁贴。

## 下载与使用

发布资产提供构建流水线实际通过的操作系统原生可执行文件压缩包，以及 SHA-256 校验文件。Windows 提供 ZIP，Linux/macOS 提供 tar.gz；解压后运行 `infinite-mosaic-gallery`（Windows 为 `infinite-mosaic-gallery.exe`）。启动时可附加图片目录路径作为参数。

Linux 可执行文件在 Ubuntu 24.04 环境编译，需要兼容的图形环境及运行库。macOS/Windows 未签名、未公证，也**不是安装程序**；首次启动可能需要系统安全确认。请从 GitHub Releases 官方页面下载。GitHub 发布页也自动提供源码归档；Release 附带本次构建解析的 `Cargo.lock`。

## 已知限制

- 文件系统事件触发全量扫描，不是索引数据库级增量更新；极端海量文件仍需实机评测。
- 以相对路径记录图片身份，因此重命名可能产生新空间槽位；已有槽位不会随删除自动回收。
- 原图查看仍可能解码高分辨率图片；GPU 缓存是条目数限制，并非严格字节上限。
- 尚未完成 1k/10k/50k 本地图集的跨平台 FPS、GPU 峰值内存与动画截图验收。
- 用户图片目录只读；缩略图与槽位索引分别写入系统应用缓存/数据目录。

## 代码与测试

GitHub Actions 的 PR 检查执行 `cargo check`、`cargo test`，发布构建在 Linux、Windows、macOS 分别执行 `cargo build --release --locked`，并校验压缩包 SHA-256。构建通过不等于所有目标系统的 GUI 操作都经实机验收。
