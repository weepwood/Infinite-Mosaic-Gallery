## 已实施的重排设计

- 选中图片时，在其原块的 12×8 几何范围内保留 6×6 焦点区域。
- 其余图片分配到不重叠的四周区域，优先匹配距离原始位置最近的槽位。
- 改变选择或关闭时，矩形位置/宽高通过 GPUI Base spring 动态趋向目标。
- 独立检查层的矩形从选中磁贴在屏幕中的真实位置开始，由独立的 focus-progress spring 推进到居中的 980×740（或适配视口）检查区域，返回使用相同路径。减弱运动偏好使用 GPUI Base 的平台策略。
- 动画及重排的几何有纯 Rust 单元测试，但目前**没有真机视觉交互验收**。

## 验收基准

- 测试集包含：无图片目录、权限受限目录、损坏图片、中文及超长路径、1k/10k/50k 文件、横竖图混合。
- 性能：仅统计可见范围的磁贴；按实际设备验证目标 60fps（可选 120fps），不以理论渲染速度冒充实测。
- 安全：不更改源图片目录，缩略图只写专用应用缓存目录。
- 工程：每次提交必须运行 `cargo test` / `cargo check`，并追踪实际 CI 结果。
- 文件监控：确认大量照片复制后不会产生无界事件队列；Linux/macOS/Windows 不同文件系统下的事件可靠性仍需实机验证。
