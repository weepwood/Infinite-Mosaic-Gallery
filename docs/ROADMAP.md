# Roadmap / 实施与验收状态

## v0.1 · 原生画布原型

- [x] Rust 2021 + GPUI Kit 0.9 原生桌面工程
- [x] 系统文件夹选择器与命令行文件夹参数
- [x] 异步枚举当前目录、可选递归、错误与空状态
- [x] 支持 JPEG / PNG / WebP / BMP / GIF / TIFF 入口识别
- [x] 原创 12×8 编辑式矩形模板，多块镜像
- [x] 有限集合画布、指针锚点缩放、拖动画布
- [x] 按视口裁剪：只构建视口附近的磁贴元素
- [x] 点击聚焦大图、Esc 关闭、键盘上一张/下一张
- [x] 原图片目录只读，未引入上传和遥测
- [x] 相机、模板、目录扫描单元测试
- [ ] 在真实 Windows/macOS/Linux GUI 上完成构建及交互验收

> v0.1 是可运行源代码的第一轮实现，不代表已验收全部 P0 需求；运行验证以 CI 和实际桌面测试为准。

## 验收基准

- 测试集包含：无图片目录、权限受限目录、损坏图片、中文及超长路径、1k/10k/50k 文件、横竖图混合。
- 性能：仅统计可见范围的磁贴；按实际设备验证目标 60fps（可选 120fps），不以理论渲染速度冒充实测。
- 安全：不更改源图片目录，缩略图只写专用应用缓存目录。
- 工程：每次提交必须运行 `cargo test` / `cargo check`，并追踪实际 CI 结果。
